# The Power of Server Components

**August 04, 2026**

Next.js 14 introduced a major paradigm shift with React Server Components. By rendering components on the server by default, we significantly reduce the amount of JavaScript sent to the browser. 

This results in:
- Faster page loads
- Better SEO out of the box
- Less client-side execution overhead

## Why it matters for portfolios

When building a portfolio, performance is key. First impressions matter, and a slow, bloated site sends the wrong signal. By keeping interactive pieces (like our new Footer spotlight) as Client Components and everything else as Server Components, we strike the perfect balance between cinematic UI and raw performance.
